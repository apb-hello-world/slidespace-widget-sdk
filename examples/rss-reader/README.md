# RSS reader

This declarative Widget API v3 sample accepts an arbitrary RSS or Atom URL.
SlideSpace asks the user to approve the feed origin, fetches and parses the XML
itself, and renders a bounded number of compact article rows without executing
widget code. Users can customize the heading, item count, typography, row
colors, border colors, and published-date display. Interactive instances scroll
through additional requested stories without making every row fit at once.
